# AIrTourer - Site de Mentions Légales & Politique de Confidentialité

Ce dépôt contient le site web statique et les documents juridiques (conformes RGPD, App Store & Google Play Store) pour l'application mobile **AIrTourer**.

---

## 📁 Structure du projet

- **`index.html`** : Site web responsive hébergeable sur GitHub Pages avec sélection par onglets, mode sombre/clair, boutons d'impression et de copie.
- **`MENTIONS_LEGALES.md`** : Mentions Légales complètes au format Markdown prêt à copier sur Notion ou GitHub.
- **`POLITIQUE_DE_CONFIDENTIALITE.md`** : Politique de Confidentialité explicite sur le respect de la géolocalisation et des droits RGPD.

---

## 🚀 Comment déployer le site sur GitHub Pages

### 1. Enregistrer et pousser les fichiers sur GitHub

Exécutez les commandes suivantes dans votre terminal :

```bash
git add .
git commit -m "feat: ajout des mentions légales et de la politique de confidentialité"
git push -u origin main
```

### 2. Activer GitHub Pages

1. Allez sur votre dépôt GitHub : [https://github.com/riff4/airtourer_site](https://github.com/riff4/airtourer_site)
2. Cliquez sur l'onglet **Settings** (Paramètres).
3. Dans le menu de gauche, cliquez sur **Pages**.
4. Dans la section **Build and deployment** :
   - **Source** : Sélectionnez `Deploy from a branch`
   - **Branch** : Sélectionnez `main` et le dossier `/ (root)`
   - Cliquez sur **Save**.
5. Après 1 à 2 minutes, votre site sera accessible publiquement à l'adresse :
   👉 **`https://riff4.github.io/airtourer_site/`**
