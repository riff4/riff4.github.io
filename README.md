# Airtourer - Site de Mentions Légales & Politique de Confidentialité

Ce dépôt contient le site web statique et les documents juridiques (conformes RGPD, Google UMP CMP, App Store & Google Play Store) pour l'application mobile **Airtourer**.

---

## 📁 Structure du projet

- **`index.html`** : Site web responsive hébergeable sur GitHub Pages avec sélection par onglets, mode sombre/clair, boutons d'impression et de copie directe au format Markdown.
- **`MENTIONS_LEGALES.md`** : Mentions Légales complètes au format Markdown.
- **`POLITIQUE_DE_CONFIDENTIALITE.md`** : Politique de Confidentialité explicite sur le respect de la géolocalisation éphémère (sans stockage), l'absence de compte (zéro inscription / stockage SecureStore), les vidéos récompensées AdMob / UMP et la lecture audio en arrière-plan.
