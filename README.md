# AIrTourer - Site de Mentions Légales & Politique de Confidentialité

Ce dépôt contient le site web statique et les documents juridiques (conformes RGPD, App Store & Google Play Store) pour l'application mobile **AIrTourer**.

---

## 📁 Structure du projet

- **`index.html`** : Site web responsive hébergeable sur GitHub Pages avec sélection par onglets, mode sombre/clair, boutons d'impression et de copie.
- **`MENTIONS_LEGALES.md`** : Mentions Légales complètes au format Markdown prêt à copier sur Notion ou GitHub.
- **`POLITIQUE_DE_CONFIDENTIALITE.md`** : Politique de Confidentialité explicite sur le respect de la géolocalisation et des droits RGPD.
