# AirTourer - Legal Notices, Privacy Policy & AI Transparency Portal

Ce dépôt héberge le portail web statique bilingue (Français & Anglais) et la documentation juridique officielle (RGPD, Google Play Data Safety, Apple App Store, AI Act UE 2024/1689 et Google UMP CMP) pour l'application mobile **AirTourer** (v1.0.28 / Build 29).

This repository hosts the static bilingual (French & English) legal portal and official compliance documentation for the **AirTourer** mobile app.

---

## 📁 Structure du projet / Project Structure

- **`index.html`** : 
  - Site web bilingue responsive hébergé sur GitHub Pages / *Bilingual responsive website on GitHub Pages*.
  - Sélecteur de langue interactif (**FR / EN**) avec détection d'URL (`?lang=en` ou `#en`) et persistance `localStorage` / *Interactive FR/EN switcher with URL parameter support*.
  - Mode sombre / clair / *Light and dark theme support*.
  - Navigation par onglets (*À Propos*, *Mentions Légales*, *Politique de Confidentialité*) / *Tabbed navigation*.
  - Boutons d'export Markdown instantané (FR ou EN) et d'impression / *Instant Markdown copy & print buttons*.
- **Documentation légale en Français** :
  - **[`MENTIONS_LEGALES.md`](MENTIONS_LEGALES.md)** : Mentions Légales complètes (Éditeur, hébergement Supabase & GitHub Pages, AdMob/UMP et conformité AI Act Art. 50).
  - **[`POLITIQUE_DE_CONFIDENTIALITE.md`](POLITIQUE_DE_CONFIDENTIALITE.md)** : Politique de Confidentialité complète (géolocalisation éphémère 0s, zéro compte, chiffrement SecureStore, transparence IA, vidéos récompensées AdMob, service de premier plan audio).
- **English Legal Documentation** :
  - **[`LEGAL_NOTICES.md`](LEGAL_NOTICES.md)** : Full English Legal Notices (Publisher, Supabase & GitHub Pages hosting, AdMob/UMP CMP, and EU AI Act Art. 50 compliance).
  - **[`PRIVACY_POLICY.md`](PRIVACY_POLICY.md)** : Full English Privacy Policy (0s ephemeral location, zero account, SecureStore encryption, AI transparency, rewarded ads, media playback foreground service).
- **`app-ads.txt`** : Fichier de transparence IAB certifiant la propriété du compte Google AdMob (`google.com, pub-7121802546087832, DIRECT, f08c47fec0942fa0`).
